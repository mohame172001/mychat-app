# Privacy Implementation Notes

- Privacy policy, terms, data deletion, and data inventory must stay aligned with actual storage.
- MyChat currently documents no AI/LLM processing of Meta/user data. Future AI reply generation requires privacy and security review.
- Raw text/token exposure is prohibited in logs, diagnostics, public responses, and admin detail unless explicitly reviewed.
- Backup deletion caveats, audit retention, and data deletion escalation are documented in data inventory and incident response docs.
- Brand rename after Meta approval requires privacy, terms, Meta dashboard, Google OAuth consent, and email sender review.
