# Alexandria

Unmodified Arabic and Latin WOFF2 variable subsets from
`@fontsource-variable/alexandria` version 5.3.0 (npm).

Upstream: https://github.com/Gue3bara/Alexandria

Copyright 2022 The Alexandria Project Authors. Distributed under the bundled
SIL Open Font License 1.1. Only the Arabic locale selects this self-hosted
family; the English typography is unchanged. Weights 100-900 share one file
per character subset, with `font-display: swap` to avoid invisible text.
